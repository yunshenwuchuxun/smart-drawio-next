# Smart Drawio

交付完整、未压缩的 mxGraph XML，保存为用户可继续编辑的 `.drawio` 文件。本 Skill 自包含；MCP 是可选增强，不要求启动网站、安装完整 CLI 或另配生成模型。

## 工作方式

1. 从需求中确定节点、关系、分组和主阅读方向。保留用户提供的术语、数量和业务含义；资料没有给出的实验结果不填成事实。创建 XML 或修改已有文件前，按需读 [格式与修改规则](references/xml-format.md)。
2. 用助手自身模型构造 XML。需要模板时复制并改造 [科研结构图](assets/research-architecture.drawio) 或 [分支流程图](assets/decision-flow.drawio)。已有图默认保留未涉及的 ID、节点位置、连线和页面；用户要求重排时再调整布局。
3. 有 Smart Drawio MCP 时，按 [MCP 工具选择](references/mcp-tools.md) 调用校验及可选样式操作。没有 MCP 时，用本目录内的 Python 3 标准库脚本校验：

   ```bash
   python3 "<已安装的 skill 目录>/scripts/validate_drawio.py" "<待交付文件>.drawio"
   ```

   将占位符换成实际路径。脚本只读文件，输出 JSON；退出码 `0` 表示通过、`1` 表示失败、`2` 表示当前格式或环境不支持。它检查 XML、基础 mxGraph 结构及逐页引用，不验证渲染布局，也不等同于 MCP 的完整校验。
4. 校验失败时保留原文件，修正副本并重新校验。XML 截断优先补全缺失内容；仅在用户要求修复或已授权恢复时裁掉残缺尾部，并说明删掉了什么。压缩页面需先通过可用的 Draw.io 编辑器另存为未压缩 XML；本 Skill 的离线脚本不解压页面。
5. 检查 [交付质量](references/quality.md)，由助手把最终 XML 写入用户指定目录或当前工作区的 `.drawio` 文件，返回可点击的文件链接。MCP 返回 XML 不代表文件已经写入磁盘。需要预览、PNG/SVG/PDF 时使用当前可用的 Draw.io 渲染或导出能力；没有渲染器时交付可编辑文件并说明尚未视觉检查。

## 科研、架构和流程表达

- 科研图：区分输入、模块、输出和训练/辅助关系；沿用论文定义的符号，必要时提供图例和单位。
- 架构图：按职责、服务或部署边界分组；箭头表达明确的数据或调用方向，标签注明关键协议或载荷。
- 流程图：判断节点的出口标明条件，分支能回到主流程或明确结束；避免用装饰箭头代替业务关系。

模板是通用结构示例，不代表特定模型、产品架构或期刊格式保证。只读取与当前任务相关的参考资料；不修改用户的 MCP 配置或发布图表到外部服务。
